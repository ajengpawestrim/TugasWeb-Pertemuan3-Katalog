# Katalog Produk - Tugas Rutin 3

Halaman katalog produk kamera vintage yang responsif, dibangun menggunakan Bootstrap 5.

## Fitur
- Navbar responsif dengan hamburger menu
- Grid produk yang menyesuaikan 1-2-3 kolom sesuai ukuran layar
- Form pemesanan
- Menggunakan clamp() untuk typography
